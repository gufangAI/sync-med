# 内容发布闸 · 铁律(创始人 2026-09-01 钦定)

> 「不审核直接发出去,那不是坑我?」——创始人原话。这条闸就是为此立的。

## 铁律

**任何自动生成的内容(图文卡/视频/文案),未经创始人过目,一律不得发布到任何外部平台。**

产线的边界到"产出 + 存档"为止:
```
渲染卡片 → 存 123(cards 文件夹) → ⛔ 停在这里 → 【创始人审核】→ 才允许发布
```

## 为什么必须有这道闸(2026-09-01 实证,不是假想)

第一批 3 张卡自查就抓出两个**发出去会真出事**的错:

1. **域名印错**:卡上印 `guyaofang.cn` —— 实测该裸域**已挂(HTTP 000)**,主站是 `gufangai.com`。
   发出去 = 给用户一个打不开的网址。(已修)
2. **出处存疑**:大承气汤标「出自《医宗金鉴》」——它是《伤寒论》方,《医宗金鉴》只是转载。
   数据源 `sue_formulas.book` 给的是"这条记录抄自哪本书",不等于"此方首出何书"。
   **中医一眼看出来,平台专业性当场崩**。(未修:需出处校验逻辑)

自动产线一旦接上发布,这类错就是**批量**发出去,而且**发出去收不回**。

## 实施

- ✅ 产线**不含任何发布代码**(social-auto-upload 等一律不接进自动流)
- ✅ 卡片只到 123 归档 + Actions artifact,人可下载查看
- ⛔ 接发布环时**必须**先建审核队列(待审/通过/驳回),通过的才进发布池
- ⛔ 任何"AI 生成 → 直接发"的链路,一律视为违规
