## 二、数据层(D1 · guyaofang-db)
```sql
CREATE TABLE IF NOT EXISTS sue_formulas (
  formula_id   INTEGER PRIMARY KEY AUTOINCREMENT,
  name         TEXT NOT NULL,            -- 原书方名(繁体原样)
  name_norm    TEXT NOT NULL,            -- 归一键(简体+异体归一,用于跨书聚合)
  book         TEXT NOT NULL,            -- 出处书名
  text_id      TEXT NOT NULL,
  vol          INTEGER,
  composition  TEXT NOT NULL,            -- JSON数组:药味
  indication   TEXT,                     -- 主治
  quote        TEXT NOT NULL,            -- 原文引文(20-80字,substring已验)
  gate         TEXT NOT NULL DEFAULT '三闸全过',
  tier         TEXT NOT NULL DEFAULT '原文直证',
  batch_id     TEXT NOT NULL,            -- 版本印:哪次挖的
  created_at   INTEGER NOT NULL
);
CREATE INDEX idx_sf_namenorm ON sue_formulas(name_norm);
CREATE INDEX idx_sf_text ON sue_formulas(text_id);
CREATE UNIQUE INDEX idx_sf_dedup ON sue_formulas(text_id, name, composition);
```
同名跨书 = 各自保留(不同书的同名方组成可不同,是学术价值不是脏数据);聚合靠 name_norm 视图层做。
