## 一、终态定义(竣工线)
- A档390册:右栏随翻页逐页同步,页面显示「逐页同步」徽标+置信度;
- B档126册:锚点页精准跳、锚间页取邻近锚插值(标"约")
- C档/无OCR册:保持现状(整卷显示),**零回归**;
- 数据可整层回滚(删表/关开关即回现状)。

## 二、数据层(D1 · guyaofang-db)
新表(migration 编号顺延现有 migrations/ 下一号):
```sql
CREATE TABLE IF NOT EXISTS book_page_anchors (
  book_id     TEXT NOT NULL,
  page        INTEGER NOT NULL,
  text_id     TEXT NOT NULL,
  char_offset INTEGER NOT NULL,      -- 该页在全文规范化文本中的起点
  confidence  REAL NOT NULL,          -- 锚定置信(多锚中位一致度)
  tier        TEXT NOT NULL,          -- A/B(C与no_ocr不入表)
  PRIMARY KEY (book_id, page)
);
CREATE INDEX IF NOT EXISTS idx_bpa_text ON book_page_anchors(text_id);
```
预估行数:A档390册×均值~60页≈2.3万行 + B档锚点页≈0.6万行 ≈ **3万行**(D1 体量无压力)。

## 三、导入线(云端 Actions,零本地算力)
- 新 workflow `align_import.yml`(dispatch-only):对 A/B 档册重跑已产线化的对齐脚本(align_full.py 已带每页 offset 计算),输出 anchors JSONL → 分批(≤500行/批)UPSERT 入 `book_page_anchors`;幂等(主键冲突覆盖)。
- 运行成本:8路矩阵约40-60分钟,免费额度内;R2 只 get_object 构造 key,零 LIST(沿用产线化脚本已验证访问模式)。

## 四、API 层(1 个端点扩展,零新端点)
`/api/text/by-image` 增加可选参数 `?page=N`:
- 有锚点:查 `book_page_anchors` 得 char_offset → 返回全文该 offset 前后窗口(前200字+后1200字,段落边界对齐)+ `{tier, confidence, anchored:true}`;
- 无锚点行(C档/未导入/页超界):行为与现状完全一致(整卷),`anchored:false`——**向后兼容,老前端零感知**。

## 五、前端(ReaderPage 右栏)
- 翻页事件已有;右栏在 `anchored:true` 时请求带 page 参数并滚动到窗口段落,顶部显示「逐页同步·A档」徽标(B档显示「骨架同步·约」);
- 开关:`localStorage` + 全局常量 `PAGE_SYNC_ENABLED`(灰度阀,秒关);
- C档书 UI 无任何变化。
